Git & GitHub, by running it

Every lab below is a real command sequence, broken into buttons. Click any command and two things happen at once: a terminal shows the exact output Git would print, and a diagram beside it shows what just moved — a file crossing into staging, a branch splitting off, a commit landing on the wrong side of a merge.

Nothing here needs an install. Work top to bottom, or jump straight to whichever command you keep forgetting.

How to use it: each button is one real command — click them left to right to follow a lab's story, or jump to any one directly to see exactly what that command does on its own.
