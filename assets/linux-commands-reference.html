File Permissions & Ownership

CommandWhat It DoesExample
chmodChanges a file/directory's permissionschmod 755 script.sh
chmod +xMakes a file executablechmod +x deploy.sh
chmod -RApplies permission changes recursively to a directorychmod -R 644 uploads/
chownChanges a file's owner (and optionally group)chown user:group file.txt
chown -RChanges ownership recursivelychown -R www-data:www-data /var/www/site
chgrpChanges just the group ownership of a filechgrp developers project/
umaskShows/sets the default permissions new files getumask 022
sudoRuns a single command with administrator (root) privilegessudo apt update
sudo -iOpens a full root shell sessionsudo -i
suSwitches to another user (often root)su - username
getfacl / setfaclViews/sets fine-grained access control lists beyond basic chmodsetfacl -m u:alice:rw file.txt
Understanding chmod's numbers: each digit is a sum — 4 = read, 2 = write, 1 = execute. chmod 755 means owner gets 7 (4+2+1 = read+write+execute), group and others get 5 (4+1 = read+execute).

Redirection, Pipes & Operators

SymbolWhat It DoesExample
|Pipes one command's output into another command's inputps aux | grep nginx
>Redirects output to a file, overwriting itls > filelist.txt
>>Redirects output to a file, appending to itecho "done" >> log.txt
<Feeds a file's contents in as a command's inputsort < names.txt
2>Redirects only error output (not regular output) to a filecommand 2> errors.log
&>Redirects both regular and error output to the same filecommand &> full_output.log
&&Runs the second command only if the first one succeedsmake && make install
||Runs the second command only if the first one failsping -c1 host || echo "unreachable"
;Runs commands one after another regardless of success/failurecd /tmp; ls
$(command)Substitutes a command's output directly into another commandecho "Today is $(date)"
!!Repeats the last command runsudo !! (re-runs the last command with sudo)

Bash Scripting Essentials

ConceptWhat It DoesExample
Shebang lineTells the system which interpreter runs the script#!/bin/bash (first line of the file)
Making a script runnableCombine chmod +x with ./ to execute itchmod +x deploy.sh && ./deploy.sh
VariableStores a value for reuse (no spaces around =)name="Alice" then echo $name
Reading inputWaits for the user to type somethingread -p "Enter your name: " name
If statementConditional logicif [ "$name" == "Alice" ]; then echo "Hi Alice"; fi
For loopRepeats a block for each item in a listfor f in *.txt; do echo "$f"; done
While loopRepeats a block while a condition stays truewhile [ $i -lt 5 ]; do echo $i; i=$((i+1)); done
FunctionGroups reusable commands under a namegreet() { echo "Hello $1"; } then greet Alice
Argument variables$1, $2, etc. hold arguments passed to a script./script.sh foo → $1 is "foo" inside the script
Exit status$? holds the last command's exit code (0 = success)ls /nonexistent; echo $?
